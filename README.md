# Reborn — Releases

**Reborn** は、複数モニター環境でウィンドウの配置を保存・復元する macOS メニューバー常駐アプリです。
このリポジトリは **配布用リリース（DMG）の置き場** です。アプリ本体のソースコードは別リポジトリで管理しています。

> 「MacBook をデスクに戻したら、何もしなくても作業環境が元通りになる」

## ダウンロード

最新版は [**Releases**](https://github.com/den0206/reborn-releases/releases/latest) から `Reborn-X.Y.Z.dmg` を取得してください。

アプリ内の「情報」タブ →「アップデートを確認」でも最新版の有無を確認できます
（ネットワーク通信はこのボタンを押したときの GitHub 公開リリース取得 1 回のみ）。

## インストール

1. ダウンロードした `Reborn-X.Y.Z.dmg` を開く
2. `Reborn.app` を `Applications` フォルダにドラッグ
3. 初回起動時、**アクセシビリティ権限**を求められます
   — ウィンドウを移動・リサイズするために macOS の許可が必要です
   （読み取るのは位置・サイズ・タイトルのみ。ウィンドウ内容やキー入力にはアクセスしません）

> **署名なし DMG の場合**: Gatekeeper に「開発元を確認できません」と表示されたら、
> `Reborn.app` を右クリック →「開く」で一度だけ許可してください。

## 動作環境

| 項目 | 内容 |
|------|------|
| OS | macOS 14 Sonoma 以降 |
| アーキテクチャ | Apple Silicon / Intel（Universal Binary） |
| 必要権限 | アクセシビリティ（必須）／通知（任意） |

## プライバシー

- **データはすべて Mac 内にのみ保存されます。**
- ネットワーク通信は、あなたが「アップデートを確認」を押したときの GitHub 公開リリース取得 1 回**だけ**です。
- ウィンドウの内容・キー入力・利用状況などは一切送信・収集しません。

## バージョン表記について

タグは `Ver_X.Y.Z` 形式です。同一 `X.Y.Z` を再ビルドしたリリースには `Ver_X.Y.Z+N`（例: `Ver_0.0.1+1`）が付き、
アプリのアップデート確認では `X.Y.Z+N` を `X.Y.Z` より新しい版として扱います。
